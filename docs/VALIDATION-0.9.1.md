не считаются проверенными. Свойства default материала теперь зарегистрированы
через оригинальный IPhysicsSurfaceProps до контактной симуляции.

Вывод карты — наш Metal адаптер. Оригинальные graphical shaderapi/materialsystem,
PVS/lightmaps/displacement, модели и анимации ещё не перенесены. Пользовательский
BSP имеет только polygon preview; engine brush-мир остаётся встроенным.

## Проверка на физическом iPhone

Пользовательский лог версии 0.9.1 подтверждает все 50 стартовых проверок,
загрузку BSP brush-модели и VTF в Metal, GPU completion на Apple A18, два
pause/resume и смену ориентации. Устройство: iPhone 16e, iOS 18.6.2; экспорт
на кадре 3211. Повторную серию тестов и импульс на физическом устройстве
этот лог не подтверждает.

1. Подписать и установить IPA; дождаться комнаты и 50 PASS.
2. Слева тянуть палец для движения, справа — для обзора; пройти к стене.
3. Выполнить source_physics_impulse, source_physics_reset и source_selftest.
4. Свернуть на 20 секунд после завершения тестов, вернуться, проверить управление.
5. Экспортировать лог через Share diagnostic log.

Прогресс около 50% — инженерная оценка минимального порта движка, не процент
исходников и не готовность CS:GO. Загружать модель персонажа и строить его
ragdoll предстоит на следующих этапах; сейчас проверен один настоящий шарнир.
