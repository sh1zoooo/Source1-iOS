# Ресурсы игры и ClientMod VPK (0.31.0 / build 34)

Ресурсную часть Android-кеша можно пробовать отдельно от Android-приложения.
APK и `.so` не исполняются на iOS; ClientMod требует отдельного переноса игрового
клиента и его механик. Файлы данных тоже должны совпадать с поддержанными форматами.
Архив Clientmod Rec1.4 из предоставленной ссылки проверен локально: SHA256
`75b56b7eaf6b495b1234b3de2aaf7a3cf5eee3b590223fcfac88627a31aac973`, 969
записей, 31 BSP версии 19/20 и 48 VPK-файлов. APK/SO/DLL в архиве нет.

У ClientMod Android в опубликованной инструкции отдельно представлены engine APK,
client APK и архив ресурсов. Обновление карты устанавливается в `cm/maps`.
Источники: [канал разработчиков](https://t.me/s/clientmod_android_updates?before=39),
[описание ClientMod](https://forum.clientmod.ru/threads/o-clientmod-v3.249/).
Эти страницы объясняют устройство пакета, но не доказывают его совместимость с iOS.

## Размещение

В приложении «Файлы» откройте папку Source1IOS, затем `Source1IOS/content`.
Сохраните внутри распакованные папки игры и общих ресурсов:

| Папка | Назначение |
| --- | --- |
| `cm` | Игровые ресурсы ClientMod Android, если пакет использует это имя |
| `cstrike_clientmod` | Альтернативное имя каталога игрового мода |
| `cstrike` | Ресурсы CS:S |
| `hl2` | Общие ресурсы Source/HL2 |
| `platform` | Общие интерфейсные ресурсы; интерфейс игры пока не запускается |

При запуске подключаются все существующие игровые папки в порядке
`cm`, `cstrike_clientmod`, `cstrike`, затем `hl2` и `platform`. Loose files и
вложенные многотомные VPK v1/v2 читаются напрямую оригинальным Source
`CPackedStore`. ZIP/RAR/7z нужно распаковать заранее; сам `.rar` iOS-порт не
открывает.

Можно подключить папку без перезапуска:

```
source_content_mount cm
source_content_probe models/weapons/w_eq_molotov_thrown.mdl
source_clientmod_demo
source_bsp_load maps/de_dust2.bsp
source_model_load models/weapons/w_eq_molotov_thrown.mdl
source_content_unmount cm
```

Имена карт/моделей — примеры; нужный файл должен существовать в вашем наборе данных.
Подключение добавляет GAME search path после собственной папки `game`, сохраняя
её приоритет и DEFAULT_WRITE_PATH. Тестовые файлы приложения не записываются
в импортированный каталог. `gameinfo.txt` и конфигурации из кеша не исполняются.

## Границы

Сейчас это загрузка данных в ограниченный preview: BSP 19–21, MDL 48/49, VVD 4/VTX 7,
поддержанные VMT/VTF и простые embedded/external ANI tracks. Большая карта,
другая версия модели, HDR-only освещение или неподдержанный shader/animation
могут быть отклонены или отображены неполно. Успешное подключение папки не означает
запуск ClientMod или CS:S.

Путь задаётся относительно `content`: до 120 символов, букв/цифр, `_`, `-`, `/`.
До 16 подключений; проверяется до 100000 записей и 32 уровней вложенности.
Симлинки и пути за пределами content отклоняются. Папки с автоматически открываемым
legacy `zip0.zip` тоже отклоняются. До 32 VPK directory-файлов на подключение,
64 MiB на directory, 512 частей, 512 MiB на часть и 8 GiB суммарно. До передачи
оригинальному парсеру проверяются signature/version, дерево, preload/embedded
ranges, наличие и размер каждой части. Повреждённый VPK отклоняет подключение.

Native contracts проверяют loose BSP/MDL/VMT/VTF и вложенный VPK v2, повторное
подключение/отключение, malformed VPK, traversal/symlink/ZIP rejection.
Отдельный локальный прогон реального Clientmod Rec1.4 подключил `cm`, `cstrike`,
`hl2`, `platform`: 9 directory VPK, 38 частей, около 6.09 GB. Через оригинальную
файловую систему прочитаны WAV/VMT/VTF/MDL/VVD/VTX/PHY; модель молотова MDL48
загрузилась как 605 вершин, 780 треугольников, 2 mesh и две текстуры 512×512.
Это всё ещё не запускает игровые правила, HUD, оружие или сетевой клиент.
